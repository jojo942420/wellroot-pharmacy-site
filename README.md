# Wellroot Pharmacy

A responsive, one-page promotional website concept for a neighborhood pharmacy in Accra. Built with plain HTML, CSS, and JavaScript; no build step or dependencies are needed.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Before publishing

This is a fictional brand and a design starter. Replace the demo address, email, opening hours, and photography with verified pharmacy details and approved assets. Confirm local pharmacy advertising requirements before publication. The page offers general promotional content and does not provide medical advice or online medicine sales.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current year
